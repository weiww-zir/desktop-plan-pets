# 小黑手帐 · desktop-plan-pets

一只可以记待办的 Windows 桌面宠物。点一下小黑，日历手帐就在它上方打开。红色角标贴着右耳，显示当天还没完成的任务数。

![小黑敲键、按鼠标、被摸头和打盹](outputs/小黑互动.gif)

## 运行

下载 [小黑手帐.exe](outputs/小黑手帐.exe?raw=1)，在 Windows 上双击运行。当前版本为 **1.20.0**。

任务、周计划和窗口设置保存在当前 Windows 用户的 `%LOCALAPPDATA%\XiaoheiPlanner\planner.xml`。移动程序或更新版本后，仍会读到原来的手帐。

## 使用

- **敲键盘**　只打字时，小黑面前只出现迷你键盘。它用前爪敲对应的键，按住键时爪子停在键帽上，尾巴保持静止。中文输入法下，身旁浮现的是当前键位。[查看敲键动图](outputs/敲键盘.gif)
- **玩鼠标**　只移动、点击或滚动鼠标时，小黑身边只出现小鼠标。它会看向光标，用右爪操作小鼠标，按键和滚轮会随动作亮起。边打字边用鼠标时，两件道具一起出现，左爪接着打字。松开后，哪件道具约 0.8 秒没再用，哪件就收起。
- **摸摸小黑**　把光标放在小黑头上来回轻抚两次，它会眯眼蹭手，冒出小爱心。单击小黑仍能打开手帐，按住拖动可以移动桌宠。
- **看它休息**　闲下来时，小黑会轮流洗脸、伸懒腰、看爪和抖耳。约 28 秒没有键鼠活动，它会趴下打盹，身旁飘出 Z。敲键或移动鼠标就能叫醒它。
- **隐藏按键**　右键小黑，取消勾选「显示按下的键」，打字时它会闭眼，键名也会隐藏。带 Windows 密码标志的原生输入框会自动隐藏按键。在网页或自绘密码框输入时，可以手动关掉显示。小黑只在本机显示当前按键。
- **看白蝶**　右键小黑，选择「白色小精灵围绕」即可播放 7.2 秒的动画。一只白蝶从左前爪左下方飞向画面左侧。[查看动图](outputs/白色小精灵围绕.gif)
- **记当日任务**　点小黑打开手帐，再点「＋ 新建任务」直接输入。点任务右侧的「⋯」，可以添加子任务、编辑、删除或转入长期清单。主任务和子任务都能打勾。
- **看长任务**　鼠标停在带省略号的任务或子任务文字上，片刻后会显示这一行的全文。
- **记长期任务**　长期清单在当日清单上方，点「＋ 新建长期任务」即可输入。点任一清单标题旁的箭头，可以单独展开或收起，手帐会记住各自的状态。已有任务可以从「⋯」菜单选「转长期」，子任务和勾选进度会一起保留。
- **查看月历**　在清单下方点选日期，即可查看或新建当天的任务。日期数字下方显示农历，初一显示月份名，遇到已收录的节日则显示节日名。「休」和「班」分别表示放假和调休上班，目前收录了中国内地 2025 至 2027 年的安排。
- **收起或翻看月历**　标题显示所选日期和星期，点旁边的箭头可收起月历。窗口放不下整月时会优先显示所选日期所在的一周，在日期区滚动可查看其他周。
- **看提醒**　每日 18:00，未完成的当日任务会标红并顺延至次日。周五 18:00 会标红所有已安排日期的未完成任务。桌宠角标和每周汇总也只统计有日期的任务。
- **写周计划**　切换到「每周汇总」，可以查看一周的完成情况，也可以点「写周计划」记录安排。
- **调大小和位置**　拖动小黑可以移动它。右键选择「桌宠大小」，或按住 Ctrl 滚动鼠标滚轮微调。当日任务多时，手帐会自动加高，上方留出空隙。放不下的任务可以滚动查看。也可以拖动手帐的边或角调整大小，双击边缘可自动适配。

## 从源码构建

在装有 64 位 .NET Framework 4.x 和 WPF 的 Windows 上，从仓库根目录打开 PowerShell，运行以下命令。

```powershell
.\src\Build.ps1
```

编译结果位于 `outputs\小黑手帐.exe`。若桌宠正在运行，可用 `-Destination` 指定其他文件名。应用源码、图标和构建脚本在 `src`，回归检查在 `tests`，图标和动画预览的生成程序在 `tools`。

例如，下面的命令会编译并运行任务顺延检查，使用 `work` 下的临时数据。

```powershell
New-Item -ItemType Directory -Force .\work | Out-Null
.\src\Build.ps1 -Destination "$PWD\work\ScheduleCheck.exe" -Main Xiaohei.ScheduleCheck -ExtraSource "$PWD\tests\ScheduleCheck.cs" -Console
.\work\ScheduleCheck.exe
```
